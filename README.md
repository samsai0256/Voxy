# Voxy for Minecraft 1.21.1 / NeoForge

This repository contains an unofficial port of Voxy 0.2.4-alpha to Minecraft
1.21.1 and NeoForge. The ready-to-install JAR is available in
[`release/`](release/).

Required versions:

- Minecraft 1.21.1
- NeoForge 21.1.209
- Java 21
- Sodium 0.6.13 for NeoForge 1.21.1

Iris 1.8.12 is optional. See [PORTING.md](PORTING.md) for installation,
validation results, build instructions and known limitations.
